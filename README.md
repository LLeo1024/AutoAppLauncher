# AutoAppLauncher（定时启动器）

一款 Android 定时任务工具，到点自动打开你指定的 App。支持熄屏触发、节假日识别、随机时间段等高级功能。专为 MIUI 系统深度适配，解决小米手机后台杀进程、锁屏无法拉起等痛点。

## 核心功能

- **定时拉起 App** — 自定义时间，到点后自动打开目标应用
- **随机时间段触发** — 选取一个时间段，系统在区间内随机选一个时间点触发，每次都不一样
- **熄屏也能触发** — 锁屏/屏幕关闭状态下可靠拉起目标 App，不漏触发
- **任务查看与修改** — 随时查看和编辑已创建的任务
- **开机自动启动** — 手机重启后自动恢复所有定时任务，无需重新设置
- **后台常驻保活** — 前台服务 + 常驻通知，最大程度防止被系统杀死

**支持 6 种重复模式：**

| 模式 | 说明 |
|------|------|
| 仅一次 | 触发后自动取消，适合临时用 |
| 每天 | 每天固定时间触发 |
| 每周 | 每周指定星期几触发 |
| 法定节假日 | 仅在春节、国庆等法定放假期间触发（联网获取） |
| 非法定节假日 | 法定放假期间不触发，其余日子正常执行 |
| 法定工作日 | 仅在法定工作日触发，调休补班也算工作日（联网获取） |

## 快速上手

### 三步创建你的第一个任务

1. **打开 App → 点击右下角「+」按钮**，进入新建任务页面
2. **选择目标应用** — 点击「选择应用」，从列表中选你要定时打开的 App
3. **设置触发时间 → 保存** — 选择固定时间或随机时间段，选择重复模式，点击保存

任务创建后会在列表中显示，到点自动触发。

### 钉钉自动打卡（推荐场景）

配合钉钉的「极速打卡」功能，可实现到点全自动打卡，无需手动操作：

**1. 开启钉钉极速打卡：**

打开钉钉 → **我的** → **设置** → **考勤设置** → 开启 **极速打卡**（上班/下班各一个开关，都打开）

**2. 在 AutoAppLauncher 中创建任务：**

- 目标应用：选择 **钉钉**
- 触发时间：设为上班/下班打卡时间（建议提前 1-2 分钟）
- 重复模式：选择 **法定工作日**（调休补班也会自动打卡）

**3. 使用前请检查：**

- 钉钉极速打卡是否已开启
- 钉钉是否保持登录状态
- 手机定位是否打开（极速打卡仅在考勤时间范围内生效）

### 其他使用场景

- 每天定时打开背单词/学习 App，养成习惯
- 固定时间打开运动 App 提醒锻炼
- 随机时间段打开音乐 App，每天都有小惊喜

## 系统权限配置

> 安装后请务必完成权限配置，否则定时任务可能无法正常触发。

App 内「权限设置」页面可点击对应项直接跳转到系统设置。不同品牌手机的后台限制机制不同，请根据你的手机品牌展开对应章节进行配置。

### 第一步：熄屏触发设置（所有品牌必配）

App 已通过「全屏通知 + 屏幕唤醒 + 透明桥接 Activity」三重机制适配熄屏拉起，但为了确保万无一失，建议完成以下三步系统设置。否则锁屏状态下可能出现拉起失败。

**① 关闭锁屏密码**

关闭后，App 拉起目标应用时无需手动解锁，可直接进入应用。

| 品牌 | 设置路径 |
|------|---------|
| 小米 / Redmi | 设置 → 密码与安全 → 锁屏密码 → 关闭 |
| 华为 / 荣耀 | 设置 → 生物识别和密码 → 关闭密码 |
| OPPO / 一加 | 设置 → 密码与指纹 → 锁屏密码 → 关闭密码 |
| vivo / iQOO | 设置 → 指纹、面部与密码 → 关闭锁屏密码 |
| 三星 | 设置 → 锁定屏幕 → 屏幕锁定类型 → 无 |
| 其他 Android | 设置 → 安全 → 锁屏 → 无 |

> 如果锁屏密码用于支付/隐私保护不便关闭，可跳过此步，但熄屏拉起时需要手动解锁一次。

**② 开启「不锁定屏幕」**

此功能在开发者选项中，开发者选项默认隐藏，需先开启。不同品牌操作如下：

| 品牌 | 先开启开发者选项（连点 7 次） | 再开启「不锁定屏幕」 |
|------|---------------------------|-------------------|
| 小米 / Redmi | 设置 → 我的设备 → 全部参数 → 连点「MIUI 版本」 | 设置 → 更多设置 → 开发者选项 → **直接进入系统** → 开启 |
| 华为 / 荣耀 | 设置 → 关于手机 → 连点「版本号」 | 设置 → 系统和更新 → 开发人员选项 → **不锁定屏幕** → 开启 |
| OPPO / 一加 | 设置 → 关于手机 → 连点「版本号」 | 设置 → 其他设置 → 开发者选项 → **不锁定屏幕** → 开启 |
| vivo / iQOO | 设置 → 关于手机 → 连点「软件版本号」 | 设置 → 系统 → 开发者选项 → **不锁定屏幕** → 开启 |
| 三星 | 设置 → 关于手机 → 软件信息 → 连点「编译编号」 | 设置 → 开发者选项 → **不锁定屏幕** → 开启 |
| 其他 Android | 设置 → 关于手机 → 连点「版本号」 | 设置 → 系统 → 开发者选项 → **Stay awake** → 开启 |

> 如果开发者选项中找不到「不锁定屏幕」或类似选项，只需完成 ①（关闭锁屏密码）即可，App 仍可正常在熄屏状态拉起目标应用。

**③ 关闭锁屏清理内存**

部分手机会在锁屏时自动清理后台应用，导致 App 被杀而无法触发任务。需要关闭此功能：

| 品牌 | 设置路径 |
|------|---------|
| 小米 / Redmi | 桌面打开「手机管家」→ 优化加速 → 右上角齿轮设置 → 锁屏清理内存 → 设为「永不」 |
| 华为 / 荣耀 | 桌面打开「手机管家」→ 右上角设置 → 锁屏清理内存 → 关闭 |
| OPPO / 一加 | 桌面打开「手机管家」→ 右上角设置 → 锁屏自动清理 → 关闭 |
| vivo / iQOO | 桌面打开「i管家」→ 设置 → 锁屏加速清理 → 关闭 |
| 三星 | 设置 → 设备维护 → 电池 → 高级设置 → 关闭「自动优化」（如有） |
| 其他 Android | 在手机自带的管家/安全中心类应用中，找到锁屏清理相关选项并关闭 |

> 小米旧机型（MIUI 12 以下）「手机管家」可能显示为「安全中心」，操作路径相同。

## 技术信息

以下内容面向开发者或对技术实现感兴趣的读者。

### 技术亮点

- **MIUI 深度适配** — 引导开启自启动、省电无限制、后台弹窗 3 项关键权限
- **三重熄屏保障** — 全屏通知 + 屏幕唤醒 + 透明桥接 Activity，确保锁屏状态下可靠拉起
- **节假日智能识别** — 联网获取法定节假日数据，本地缓存 30 天，断网时 fail-open 不漏触发
- **超小体积** — APK 仅 2.2MB

### 技术栈

- **语言**: Kotlin
- **UI**: Jetpack Compose + Material 3
- **调度**: AlarmManager (setExactAndAllowWhileIdle)
- **后台**: Foreground Service + 常驻通知
- **存储**: Room Database
- **App拉起**: PackageManager.getLaunchIntentForPackage()
- **开机自启**: BOOT_COMPLETED Receiver
- **构建**: AGP 8.7.3, Kotlin 2.0.21, KSP

### 运行环境

- 最低支持: Android 11 (API 30)
- 目标设备: 小米9 / MIUI 12.5 / Android 11
- 已适配 MIUI 12.5 系统
